# countdown-app

A tiny React + TypeScript countdown to a few hardcoded dates (midnight Pacific Time), with flip-clock tiles.

- Edit dates in `src/events.ts`.
- Requires Node 20.19+ (`nvm use` picks it up from `.nvmrc`).
- `npm install` then `npm run dev` → http://localhost:5173/countdown-app/
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
